# 🍔 Online Food Delivery Analysis: Data-Driven Business Insights

## 📌 Project Overview

This project analyzes online food delivery data to understand customer behavior, delivery performance, restaurant performance, revenue, profit, and cancellations.

The project uses Python, SQL, MySQL, and Streamlit to perform data cleaning, exploratory data analysis, business analytics, and interactive dashboard development.

## 🎯 Objectives

- Understand customer ordering behavior
- Identify delivery and operational inefficiencies
- Evaluate restaurant and cuisine performance
- Analyze revenue and profit trends
- Understand cancellation patterns
- Track important business KPIs
- Provide data-driven business recommendations

## 📊 Dataset

- Records: 100,000 online food delivery orders
- Features: 25+ customer, order, restaurant, delivery, and financial attributes
- Domain: E-Commerce / Food & Beverage / Logistics

## 🧹 Data Cleaning & Preprocessing

The dataset was cleaned and prepared for analysis by:

- Handling missing values
- Treating outliers
- Correcting invalid ratings
- Handling negative profit margin values

- Checking logical consistency
- Creating analytical fields

## 🔎 Exploratory Data Analysis

The analysis covers:

1. Customer spending analysis
2. Age group vs order value
3. Weekend vs weekday order patterns
4. Monthly revenue trends
5. Discount impact on profit
6. City-wise and cuisine-wise performance
7. Average delivery time by city
8. Distance and delivery delay analysis
9. Delivery rating vs delivery time
10. Restaurant performance
11. Cancellation analysis
12. Peak-hour demand
13. Payment mode preferences
